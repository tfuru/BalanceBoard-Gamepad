# itch.io Page Theme & Styling Guide

itch.io allows creators to customize the colors, typography, and layout of their project pages under the **"Edit Theme"** sidebar.

---

## 🎨 Recommended Color Palette (Modern Cyber / Gamer Dark Theme)

| Theme Field | Hex Color Code | Color Description |
| :--- | :--- | :--- |
| **Background Color (`bg_color`)** | `#12141c` | Deep Slate / Navy Dark |
| **Foreground / Box Color** | `#1a1d28` | Slightly lighter dark container |
| **Text Color (`text_color`)** | `#e2e8f0` | Crisp light gray for high legibility |
| **Link Color (`link_color`)** | `#38bdf8` | Vibrant Cyan Blue |
| **Button Background (`btn_bg`)** | `#6366f1` | Indigo / Electric Violet |
| **Button Text (`btn_text`)** | `#ffffff` | Pure White |

---

## ✍️ Typography Suggestions

- **Font Family**: `Inter`, `Roboto`, or `Lato` (Clean sans-serif)
- **Header Style**: Bold with slight text shadow or subtle gradient

---

## 🖼️ Banner & Background Image (Optional)

- **Page Background**: Subtle dark hex grid pattern or soft vignette gradient.
- **Header Banner**: `Shop/itch.io/assets/` にて作成する `960 x 400 px` のバナー画像をセット。
