## 🚀 かんたん3ステップ導入

1. **ESP32 にファームウェアを書き込む**
   - 付属のツールまたは PlatformIO で ESP32 にファームウェアを転送。
2. **PC アプリを起動し、ESP32 を USB 接続**
   - 常駐アプリが自動的に ESP32 のシリアルポートを検出。
3. **Wii バランスボードの SYNC ボタンを押す**
   - 電池ボックス内の赤い SYNC ボタンを1回押すだけで、ESP32 と自動ペアリング完了！
   - PC 画面で重心がリアルタイムに動くのを確認してゲームを開始できます。

## ❓ よくある質問 (FAQ)

**Q. 体重制限はありますか？**  
A. Wii Balance Board 本体の公式耐荷重である「最大136kg」まで対応しています。

**Q. PCにBluetoothがついていませんが使えますか？**  
A. はい、使えます！バランスボードとのBluetooth通信はESP32マイコンがすべて担当し、PCとはUSB有線接続でデータをやり取りするため、PC側のBluetoothの有無は関係ありません。

**Q. どのゲームパッド形式として認識されますか？**  
A. PC 常駐アプリ経由で、標準的な DirectInput / XInput 互換の仮想ゲームパッド（アナログスティック / 軸入力）としてゲーム側から認識されます。

**Q. 初心者でもファームウェアの書き込みはできますか？**  
A. はい。PlatformIO を使ったソースコードからのビルドのほか、ブラウザ（Web Serial）や専用ツールから数クリックで書き込めるバイナリも同梱しています。
