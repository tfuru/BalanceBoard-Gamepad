# BOOTH 掲載用 画像・サムネイル設計ガイド

本ドキュメントは、BOOTH 出品時に設定するメインサムネイルおよび紹介用スライド画像（全5〜6枚）の構図・テキスト配置・ビジュアル設計書です。

---

## 📐 画像サイズ・仕様

- **メインサムネイル (1枚目)**: `1200 x 1200 px` (アスペクト比 1:1) または `1920 x 1080 px` (16:9)
- **紹介用スライド画像 (2〜6枚目)**: `1920 x 1080 px` (16:9) または `1200 x 1200 px`
- **フォーマット**: PNG / JPG（軽量化推奨）

---

## 🖼 スライド構成・デザイン指示

### 1枚目：メインサムネイル（アイキャッチ）
- **役割**: 一覧やSNSシェアで目を引き、何ができる商品かを瞬時に伝える。
- **メインビジュアル**:
  - Wii バランスボードに乗ってプレイしているイメージ（またはボードとゲームパッドアイコンの合成グラフィック）
  - ESP32 ボードと PC アプリの UI スクリーンショット
- **テキスト配置**:
  - 大見出し: **Wii バランスボードを 体感ゲームパッド化！**
  - サブ見出し: **ESP32 ＆ 専用中継アプリ (Windows / Mac 対応)**
  - バッジ・タグ: `ダウンロード版` `重心リアルタイム検出` `DirectInput / XInput`

---

### 2枚目：特徴紹介（体重移動で直感操作）
- **役割**: 操作感の直感性と楽しさを伝える。
- **ビジュアル**:
  - 前後左右・重心の矢印図解（足元視点）
  - 対応ジャンルアイコン（フライト ✈️ / ドライブ 🏎 / スノボ 🏂 / VR 🥽）
- **テキスト**:
  - タイトル: **体重移動（前後・左右・重心）をアナログ入力に変換**
  - ポイント:
    - 4隅のロードセルセンサーを高精度読み取り
    - レースのステアリングやスノボのエッジ操作に最適
    - VRChat やメタバースでの立ち移動にも！

---

### 3枚目：システム接続図（かんたん構成）
- **役割**: 仕組みのシンプルさと、PCのBluetooth不要であることをアピールして導入不安を解消。
- **ビジュアル**:
  - `[Wii バランスボード]` ===(Bluetooth)====> `[ESP32]` ===(USBケーブル)====> `[PC (Flutter アプリ)]` ===> `[ゲーム]`
- **テキスト**:
  - タイトル: **Bluetooth なしの PC でも OK！シンプル接続**
  - ポイント:
    - ESP32 が直接バランスボードとワイヤレス接続
    - PC とは安定した USB 有線通信

---

### 4枚目：専用中継アプリ UI 画面
- **役割**: アプリの使いやすさと高度な調整機能を見せる。
- **ビジュアル**:
  - PC 常駐アプリの実際の画面キャプチャ（重心プロット、4隅の加重バー、設定スライダー等）
- **テキスト**:
  - タイトル: **直感的な GUI で重心モニタリング & 感度調整**
  - ポイント:
    - 重心位置をリアルタイムに視覚化
    - 感度、デッドゾーン、センター調整をスライダーで簡単設定
    - タスクトレイ常駐でゲーム中も邪魔にならない

---

### 5枚目：必要なもの & ダウンロード内容
- **役割**: 購入者が用意すべきハードウェアと、本商品に含まれるものを明確にする。
- **ビジュアル**:
  - 左側: 【ご自身で用意するもの】（Wiiバランスボード、ESP32、USBケーブル、単三電池）
  - 右側: 【本パッケージ内容】（ファームウェア、PCアプリ Win/Mac、導入ガイド、ケースデータ）
- **テキスト**:
  - タイトル: **中古で安く揃う！必要なハードウェア一覧**
  - 補足: 「ハードオフ等で 500〜1,500円程度で手に入る Wii バランスボードを活用できます」
