# プロジェクト素材（Assets）管理ガイドライン

本ディレクトリは、BalanceBoard-Gamepad プロジェクトで使用する写真、スクリーンショット、回路図・構成図、ロゴなどの各種メディア素材を体系的に管理・保管するための場所です。

---

## 📁 ディレクトリ構成と役割

```text
assets/
├── README.md                 # 本ガイドライン
├── hardware/                 # 実機・ハードウェア関連の写真・メディア
│   ├── esp32/                # ESP32 単体、ピン配置、USB接続状態の写真
│   ├── balance-board/        # Wii バランスボード外観、電池ボックス、SYNCボタン写真
│   ├── circuit/              # 配線、ハンダ付け、ブレッドボード等の基板写真
│   └── casing/               # 3Dプリントケース、組み立て・収納状態の写真
│
├── screenshots/              # PC アプリケーション（Flutter）の画面キャプチャ
│   ├── app-main/             # メイン操作画面・重心リアルタイムプロット
│   ├── calibration/          # 4隅センサー校正・キャリブレーションウィザード画面
│   ├── settings/             # 設定画面・仮想ゲームパッド（DirectInput / XInput）設定
│   └── os/                   # OS固有画面（タスクトレイ、メニューバー、通知等）
│
├── diagrams/                 # システム構成図・接続図・配線図
│   ├── connection/           # Bluetooth / USB 接続フロー概念図
│   └── pinout/               # ESP32 ピンアサイン・配線接続図
│
└── branding/                 # プロジェクトブランド・アイコン素材
    ├── icon/                 # 各サイズ・解像度のアプリアイコン
    └── logo/                 # プロジェクトロゴ・バナー背景素材
```

## 🏬 ショップ用加工画像との関係

- **元データ・撮影素材**: 本ディレクトリ（`assets/`）に生素材・ドキュメント用画像を保存します。
- **ショップ完成画像**: 各プラットフォーム向けにテキストや装飾を載せて加工した完成版画像は、各ショップ用ディレクトリ（[`Shop/BOOTH/assets/`](../Shop/BOOTH/assets/)、[`Shop/itch.io/assets/`](../Shop/itch.io/assets/)）の `images/` 配下に格納します。

## 📝 ファイル命名規則

1. **ケバブケース（`kebab-case`）を使用**:
   - すべて小文字の半角英数字とハイフン（`-`）を使用してください（スペースや大文字、日本語は不可）。
2. **名前で内容が特定できるように命名**:
   - `[対象]-[状態・部位]-[補足].[拡張子]`
   - 例:
     - `esp32-devkit-top.jpg`
     - `wii-balance-board-sync-button.jpg`
     - `app-main-monitor-light.png`
     - `app-calibration-step2.png`
     - `connection-system-flow.svg`

## 📐 推奨画像フォーマット & 最適化

| 種別 | 推奨フォーマット | 推奨解像度 / 備考 |
| :--- | :--- | :--- |
| **ハードウェア写真** | `.webp` / `.jpg` | 長辺 `1920px` 程度（Web最適化・画質85%程度） |
| **UI スクリーンショット** | `.png` / `.webp` | 等倍（1x）または 2x キャプチャ（可逆圧縮推奨） |
| **図解・ダイアグラム** | `.svg` / `.png` | 可能であればベクター（SVG）推奨 |
| **アイコン・ロゴ** | `.svg` / `.png` / `.ico` | 高解像度マスター + 各種標準サイズ |

> [!TIP]
> Git リポジトリの肥大化を防ぐため、一眼レフ等の巨大な RAW ファイルや未編集の巨大動画ファイルは直接コミットせず、必要に応じてリサイズ・圧縮した画像を格納してください。
